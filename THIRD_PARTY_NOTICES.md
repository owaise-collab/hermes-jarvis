# Third-party projects and inspiration

The companion's original source and docs use the MIT license. The runtime discovery helpers were adapted from the same author's [Hermes Local Voice Guide](https://github.com/owaise-collab/hermes-local-voice-guide), also MIT. This repository does not redistribute the following upstream packages or model weights:

- [Hermes Agent](https://github.com/NousResearch/hermes-agent): agent, skills, runtime management and desktop application.
- [llama.cpp](https://github.com/ggml-org/llama.cpp): local inference server.
- [Agents-A1-4B](https://huggingface.co/InternScience/Agents-A1-4B): reference language model; consult the actual downloaded model's license and card.
- [Faster-Whisper](https://github.com/SYSTRAN/faster-whisper): local transcription; Whisper model terms apply separately.
- [Piper](https://github.com/OHF-Voice/piper1-gpl): installed speech engine; individual voices have their own model cards and licenses.
- [Obsidian](https://obsidian.md): optional consumer of the Markdown vault, not bundled or required.

Two Chase AI Instagram posts inspired the skills/memory/voice/routing/UI sequence. No endorsement, partnership, access to the author's offered setup, or reuse of their dashboard code is implied. Brand names belong to their owners.
