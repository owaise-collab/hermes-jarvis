Hermes + this companion

This panel uses the same local model server and installed speech models as Hermes. Its model workflows have no shell, browser, email, or other agent tools.

Use Hermes Local for full agent conversations, tools, and its native voice mode. The installed /jarvis-workspace skill teaches Hermes to use this vault.

Notes and outputs persist here. Full Hermes chats keep their own session history. Panel chat is a fresh request each time; select notes to carry context forward.

Installing models, searching the web, and publishing code require internet access. Full Hermes tools can also access the network. Local inference alone is not a system-wide network sandbox.
